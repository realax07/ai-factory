# AI Factory: Конвейер Агентов

## Обзор
Этот репозиторий содержит конфигурации, настройки и правила для создания и управления агентной Mesh-сетью, предназначенной для автоматизированной разработки программного обеспечения. Наша цель — построить полностью агентный конвейер разработки, от анализа до внедрения.

## Пилотный Проект: Личная Wiki
В качестве первого пилотного проекта мы разрабатываем личную Wiki с API и веб-интерфейсом. Этот проект позволит нам отработать взаимодействие различных агентов на всех этапах разработки.

### Бизнес-аналитики (Агенты)

Мы декомпозировали роль Бизнес-аналитика на два специализированных агента:

1.  **Первичный Бизнес-аналитик:** Отвечает за сбор высокоуровневых бизнес-требований от Заказчика и формирование первичного MD-артефакта.
    *   [Инструкция](agents/ba_primary_agent.md)

2.  **Детализирующий Бизнес-аналитик:** Отвечает за валидацию и углубленную проработку высокоуровневых бизнес-требований, превращая их в детализированные спецификации.
    *   [Инструкция](agents/ba_detail_agent.md)

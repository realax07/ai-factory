## Стадия 1 — ПРОЙДЕНА (релиз v1.0, тег v1.0-mono, GitHub 2026-10-01)

Мультиагентная система-ассистент на дисциплине агентов: небольшие проверки,
harness-слой из инструкций (agents/*.md) и флоу-правил. Срез сделан тегом v1.0-mono.

## Стадия 2 — ФИНАЛИЗИРУЕТСЯ (версия 2.0)

Мультиагентная система с детерминированной state-machine, ATDD-деплоями и контролем
оркестрации через детерминированные тулы. Фактическое наполнение (уже в main):
scripts/flow_state.py, flow_transition.py, gate_runner.py, flowctl.py, flow_mode.py,
role_zone_policy.py, session_check.py + contracts/flow_control_contract.md + скилл
factory-flow. Дорабатываем сами; релиз 2.0 — после финализации, тег вручную ставит
Заказчик.

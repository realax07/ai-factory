## Принятые риски (явно)

1. **Общая ОС-учетка**: машинный enforcing работает только на штатном маршруте
   flowctl; обход через GitHub UI/локальные файлы не блокируется ничем
   (граница гарантии из ci-gates). Решение: принято (2026-10-02, J28-этап 0).
2. **Содержательное качество ревью**: проверяется форма (вердикт, мета,
   delegation), не глубина. Аудит ценности — J20 (открыт).
3. **Approve по частичному прогону**: промежуточные PR валидны без полного
   QA-хвоста (норма поэтапного Флоу 1) — риск принят, снимается финальным PR.

# PLAN-readme-rewrite: README фабрики заново, сверху вниз

**Флоу: 4** — обслуживание: документация; код, спеки, контракты, промпты не
меняются.

## Задача Заказчика (2026-11-06, дословно)

«Давай полностью переработаем его. Тайтл названия мне нравится, давай
подгоним описание под него. Нужно придерживаться структуры детализации
сверху вниз. Описать нужно что это, как установить, как пользоваться, какие
есть файлы и как что гарантируют, учесть все связи, чтобы было понятно кто
что делает, и как работает агент с этим harness. Описание должно содержать
детали для понимания и уверенности пользователя в том что это работает, но
не излишние, учитывая что он может сам посмотреть код в файла. Нужен
балланс».

## Структура нового README

Заголовок сохранен. 1 — как это работает (схема, три принципа); 2 — кто что
делает (участники, роли и модели); 3 — установка (требования, машина, Pi,
GitHub, проект); 4 — как пользоваться (флоу, план с манифестом, раннер и
стадия изнутри, приемка, как ПМ-агент работает с harness); 5 — гарантии по
слоям с честными границами; 6 — устройство репозитория, ключевые скрипты,
связи частей; 7 — проекты; 8 — куда читать дальше.

Принцип баланса: в README — что, зачем и как запустить; номера J-пунктов,
история инцидентов и полные таблицы — в docs/ и backlog/ по ссылкам.

## Проверки

- Пример манифеста из README разобран раннером (`--dry-run`): inline-форма
  `verdict: {…}` мини-парсером не поддерживается — в README блочная форма.
- Ссылки и якоря README проверены скриптом.
- Факты сверены с кодом при актуализации документации (PR #226) и
  повторно ревьюером этого пакета.

## Манифест

```yaml
pipeline:
  package: readme-rewrite
  flow: 4
  stages:
    - id: docs
      run: hermes:pm    # README — зона ПМ
    - id: flow
      run: gate:python3 scripts/flow_check.py .
    - id: code_review
      run: pi:code-reviewer
      zones: [code-reviews/readme-rewrite/review-001.md]
      verdict:
        file: code-reviews/readme-rewrite/review-001.md
        contains: "Вердикт: Одобрить"
    - id: merge
      run: hermes:pm
```

## Критерий закрытия

Ревью «Одобрить» (точность утверждений, понятность, баланс), сьют и
flow_check зеленые, CI зеленый.

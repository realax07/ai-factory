- `VERDICT_LINE_RE = ^#{1,4}\s*Вердикт\s*:?\s*(.+)$` (flow_check.py:36): «заголовком ровно `## Вердикт: approve` … без нумерации секции, без прозы» — точно. Живые пробы: `## 7. - `review-mapping.json` `{"review-002.md": ["2.1", "2.2"]}` — формат читающего конца (flow_check.py:174–191) совпадает дословно.

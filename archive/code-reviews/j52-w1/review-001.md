## Проверено живыми пробами и прогоном

- **Ось 1 (ветки, w1.1):** деривация из полного id — j51-pilot-A/B дают разные ветки, обрезки `flow/j51-pilo` нет (TC-001); длинный id → sha1[:8] ОТ ПОЛНОГО id, детерминированно, общий префикс ≠ общий хэш (TC-002, пересчитано sha1 независимо); uuid4.hex(32) идет целиком (TC-003); prepare без `--branch` несет полную ветку в плане, записи цикла и reservation (TC-004). Живая проба: выводы `branch_name_for` на 10 cid прогнаны через `git check-ref-format` — валидные проходят, три класса дыр см. замечание 2. `--branch` явный приоритетнее деривации — поведение сохранено.
- **Ось 2 (release, w1.2):** reserved→released: запись реестра СОХРАНЕНА (не удалена), worktree сохранен, зона реально освобождена (живая резервация той же зоны новой делегацией — allowed, TC-005); needs_attention-путь (TC-006); отказ на running (exit 1, refused, статус не тронут, audit чист — TC-007) и на finished (TC-010); идемпотентность: повтор → exit 0 no-op, audit-событие НЕ дублируется (TC-008); неизвестный cid/без id → exit 2 ничего не тронуто, позиционная форма работает (TC-009). Audit: тип "release" добавлен в AUDIT_EVENT_TYPES gate_runner; причина ПМ с --reason попадает в историю и audit. `released` вне ZONE_HOLDING — reconcile его не трогает, энфорсер зону не держит. Источник решения — факт реестра (контракт §13), state синхронизируется под локом. Гонка чтения prev — замечание 1.
- **Ось 3 (домены, w1.3):** без карты — дефолтное поведение байт-в-байт, включая свертку BUG-video-001 (TC-011); правила проекта применяются ДО дефолтных, при активной карте collapse выключен — кейс-домены не сворачиваются в tests/ (TC-012, e2e TC-013/015); битая карта — НЕ молчаливый дефолт: `domain_map` начинается с "error:" в payload И в артефакте, решение о починке — за проектом (TC-014); каталог домена отсутствует → WARN-исход, не молчаливый PASS (частичный skip — замечание 3).
- **Ось 4 (тесты/регресс):** 16 тестов на реальных fixture-репо Флоу 1, flowctl — реальным subprocess; трассировка TC-J52-001…015 в docstring-шапке полная, без дыр (замечание 6 — один кейс без номера).

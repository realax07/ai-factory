# Rich-editor DOM: сериализация и фокус (wiki, contenteditable)

Инвариант проекта: в БД сохраняется «чистый» sanitized HTML (без editor-хрома и токенов подсветки); любое нарушение = потеря/загрязнение контента (класс отката rich-v1).

## Сериализация
- Editor-хром (тулбары, гуттеры, панели) — только СОСЕДНИЕ узлы (sibling + absolute) или узлы с data-editor, которые санитайзер вырезает при сохранении. Обертка ВНУТРИ контентного узла (pre/td) режет или ломает контент — гуттер кода живет соседом pre.
- Подсветка/токен-спаны — только при рендере; в contenteditable код — plain+нумерация, иначе спаны уходят в PUT и нарушают инвариант «в БД чистый текст».
- Round-trip тест обязателен: DOM → PUT → GET → DOM байт-в-байт, на матрице вложенности (спойлер-в-спойлере, код-в-спойлере, табы-в-табах, глубина 5/6 unwrap).

## Enter и переносы
- Enter в contenteditable дает <br>; санитайзер, разворачивающий br, СЛИВАЕТ строки в БД («line1line2»). Закрывать двумя слоями: sanitizer эмитит текстовый \n в code-контексте + normalizeCodeInput до сериализации; дискриминирующий тест «две строки через Enter → в БД ровно line1\nline2».
- Enter в ячейке таблицы: insertLineBreak, не insertHTML (insertHTML рождает тот же br-квирк).

## Фокус и rename
- Инлайн-input внутри <button> — фокус недетерминирован вне Chromium; вкладки/шапки — div role=tab tabindex=0 (стили классом), Enter/Space для клавиатуры.
- Escape/blur-гонка rename: единая точка завершения close(committed) — первый вызов финален, blur после Escape = no-op; иначе Escape коммитит правку и pageerror replaceChild. Тест: escape→cancel, гонка детерминирована, pageerror=0.
- Режимные гейты: rename/редактирование хрома — только в режиме редактирования (гейт по editable); в статье клик по названию спойлера = toggle, не input.

## Дефолты и гейты вставки
- Спойлер всегда рождается свернутым (раскрытие — только клик; атрибут раскрытия в БД отсутствует).
- Вставка блоков — через единый guarded-вход с матрицей запретов (код-блок: никакие блоки; ячейка таблицы: не таблица; глубина ≤5), кнопка disabled с подсказкой, paste прикрывает санитайзер.
- Каретка после деструктивных операций (удаление строки/таблицы) ставится отложенно — браузер асинхронно чинит выделение.

## Лексер подсветки
- Правила без вложенных квантификаторов (ReDoS), линейное время; порог >64 КБ → plain; патологический вход в тестах.

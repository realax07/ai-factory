# Политика каналов вотчдогов (ревизия 2026-10-23, решение Заказчика: без регулярного репортинга)

## Правила

- Регулярных сообщений Заказчику НЕТ. Вотчдоги молчат при чистом состоянии (no_agent, пустой stdout = ничего не доставляется).
- Прерывание: аномалия (найден инцидент/залипшая сессия/сирота-стенд) → stdout не пуст → доставляется в origin-чат. Это ЕДИНСТВЕННЫЙ случай появления крона в чате.
- Активные джобы: session-watchdog (*/5, deliver=origin), delegate-watchdog (*/5, deliver=origin — эвристика bypass починена: делегации ПМ без project вне flowctl-реестра = норма, не обход), stand-reaper-hourly (0 * * * *, deliver=local — сироты стендов ПМ проверяет сам на приемке; в чат только если скрипт упал).
- Кроны исполняют РЕПО-копии фабрики через тонкие обертки-делегаты в `~/.hermes/scripts/` (exec к `/home/openclaw/ai-factory/scripts/<имя>.py`). Standalone-копии в `~/.hermes/scripts` запрещены: они вне контроля версий, рассинхронизируются, и фикс репо не доходит до живого крона. Переустановка оберток — ТОЛЬКО из main-checkout фабрики: путь к /tmp-worktree умирает при чистке /tmp и отстает от main (дает возврат починенного спама).
- Фоновый dry-run-контроль (stand_reaper): найденные кандидаты = сигнал через stdout, exit 0; exit 1 крон помечает как ошибку джобы — для CI/ручных проверок есть явный флаг.
- pm-instruction-relay и watchdog-daily-digest: УДАЛЕНЫ из кронов; артефакты канала в ai-factory/archive/pm-instruction-channel/.

## Процедура ПМ

1. Правка кронов: предпочтительно cronjob_manage (list/update/resume/remove); при зацикливании инструмента — прямая правка ~/.hermes/cron/jobs.json (поля enabled/deliver/paused_reason) + проверка печатью таблицы.
2. no_agent-крон с deliver=origin: пустой stdout тих, непустой уходит в чат, exit != 0 = авария в чат. Писать скрипты так: чисто → молчание; после любого изменения вотчдога — прямым прогоном боевой обертки убедиться в тишине на чистом состоянии.
3. Аномалия в чате = сигнал ПМ, не Заказчика: ПМ разбирается и докладывает в своей очереди; отдельного ответа Заказчику не требует.

# Флоу 2 — багфикс

## Состав

- BUG-NNN репорт (test-model/bugs/BUG-NNN-*.md) — обязательный вход (pr_validate).
- Фикс dev → независимое code_review (решение 2026-10-07-code-review-flow2: accept_review без approve был замкнутым кругом).
- Запрет: фикс не вводит новое поведение/API — иначе эскалация в Флоу 1 (контракт §7).

## Если баг пойман QA-раннером пакета (возврат с этапа тестирования)

1. Баг-репорт с маркером прогона (какой REPORT поймал).
2. Фикс Флоу 2 + независимое ревью.
3. Повторный прогон ПОСТРАДАВШЕГО набора отдельной делегацией (не «починил — и ладно»).
4. Отчет набора дополняется фактом перегона.

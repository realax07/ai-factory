## Критично

- «Кейсы до автотестов» — qa_author пишет из дельт спеки, не из готового кода. Нарезка без QA-контурных задач = ДЕФЕКТ плана (J39).
- Каждый Scenario дельты должен иметь кейс; каждый Must-сценарий — автотест или скриптовый прогон с REPORT.
- Независимый аудит покрытия (прецедент add-wiki REPORT-coverage-audit) — до прод-выкатки.
- Возвраты: return ревьюера → фикс → ре-ревью коротким кругом (append-only review-NNN+1); [x] только после финального approve. Баг раннера → Флоу 2 + повторный прогон набора.

# Ревью тест-кейсов

Как независимо валидировать тест-кейсы: чеклист ревью, серьезности, цикл доработки. Ревью — не формальность: кейс с дефектом экономит 5 минут ревью и сжигает часы автоматизации и дебага.

## Когда применять

- Появились кейсы в `test-model/new/<change-id>/`
- Автор вернул исправленные кейсы (повторная итерация)

Не применять для: ревью кода автотестов, ревью спек (своя процедура — см. contract 2 checks).

## Процедура

1. **Сверь покрытие с чеклистом.** Каждый CHK-N покрыт кейсом? Лишних кейсов без источника нет? Непокрытый пункт — blocker автору.
2. **Проверь каждый кейс по шести осям:**
   - трассировка: ID чеклиста указан и существует;
   - соответствие спеке: ожидаемый результат не противоречит Scenario (арбитр — спека, не мнение и не код);
   - воспроизводимость: предусловия полны, шаги атомарны;
   - проверяемость: результат объективен (код, тело, состояние);
   - данные: конкретные значения приведены;
   - негативные: ожидаемая ошибка явная.
3. **Оцени серьезность каждого замечания.** Blocker — кейс невоспроизводим/непроверяем/не соответствует спеке. Major — нарушение шаблона, потеря трассировки, двусмысленность. Minor — стилистика. Серьезность определяет судьбу вердикта, поэтому завышать и занижать одинаково вредно.
4. **Напиши review-файл** `test-model/reviews/<change-id>/review-NNN.md`: вердикт + таблица замечаний (кейс, серьезность, дефект, рекомендация). Рекомендация без конкретики («переписать получше») — трата итерации впустую.
5. **Верни или одобри.** «Вернуть» при любом blocker/major; «Одобрить» — только при их отсутствии. Перенеси одобренное в `test-model/approved/<change-id>/`.
6. **Пронумеруй итерации** (review-001, review-002...) и сохрани историю. История ревью — доказательство качества процесса, удаление = фальсификация.

## Психология ревью

Замечание адресовано кейсу, не автору. Форма «ожидаемый результат не содержит кода ошибки (спека: 404 при чужом ресурсе)» вместо «ты забыл код ошибки» — экономит цикл спора.

## Ошибки

- Выборочная проверка «по диагонали» — пропущенный blocker дороже всего ревью.
- Вердикт «одобрить» с открытыми major «чтобы двигаться» — ломает смысл контракта 5.
- Спор о поведении без спеки — стоп и эскалация, opinions не арбитр.

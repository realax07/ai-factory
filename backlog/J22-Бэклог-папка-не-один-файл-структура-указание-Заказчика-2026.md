# J22: Бэклог = папка, не один файл (структура, указание Заказчика 2026-09-30, касается обоих репозиториев — ai-factory и ekotov-wiki).

- **Статус:** ОТКРЫТО
- **Карта:** backlog/MAP.md (строка item'а)

Текущий вид (один BACKLOG.md на сотни килобайт, ~176 строк простыней) плохо масштабируется: чтение/запись целого файла на каждый item жжет контекст (J8), навигация Заказчика тяжела. Целевая структура: `backlog/` — 1 файл = 1 item (`backlog/J21-*.md`, полный текст item с фактами/корнями/мерами) + общая карта `backlog/MAP.md` одним файлом БЕЗ деталей (id, заголовок, статус, дата, связи — по строке на item; MAP — единственный файл, который читается целиком при восстановлении контекста). Правила: добавление item = новый файл + строка в MAP; закрытие item = статус в MAP (файл остается, append-only, правило 7); ссылки из AGENTS.md/PLAN.md перенацелить на MAP.md. Миграция: текущий BACKLOG.md режется на файлы по item (скриптом, история git сохраняется), BACKLOG.md заменяется ссылкой на backlog/MAP.md. Верификация: восстановление контекста ПМ читает только MAP.md; flow_check/скрипты, ссылающиеся на BACKLOG.md, обновлены и зеленые на обоих репо.

# J60. MODEL_ENFORCE — механический энфорсер маркера исполнителя 5.3-ролей (2026-11-01)

**Статус:** РЕАЛИЗОВАН (плагин flow-enforcer, Флоу 4). Остаток — см. ниже.

## Задача (из J59, «Гарантия исполнителя»)

Вопрос Заказчика: «какие гарантии, что оркестратор не запустит делегацию вместо
pi?». Правило — AGENTS.md §Оркестрация 2.1 (дисциплина); здесь — механика:
pre_tool_call-энфорсер в plugins/flow-enforcer (J43) блокирует general-делегацию
на боевых этапах 5.3-ролей.

## Реализация

- **Ворота `model_enforce_gate`** (enforcer.py): перехват `delegate_task` ДО
  разбора flow-маркеров (работает и для делегаций без канонического заголовка,
  которые в permissive проходят молча).
- **Распознавание боевого этапа** — эвристика по ключевым словам роли в goal
  (ТЗ J60): «СА», «create_change» → sa; «архитектор», «arch-review» →
  architect; «dev_task», «задача dev» → dev; «BA», «requirements» → ba.
  «СА»/«BA» — только верхним регистром целым словом (анти-ложные срабатывания).
  Ни одно слово не совпало → не боевой вызов, без директивы.
- **Guard Флоу 2/4/5:** явный маркер `flow=2|4|5` в goal гасит правило —
  свобода выбора исполнителя для bug_fix/chore/express сохранена (ТЗ J60;
  devops/qa/docs-ключевые слова в список 5.3 не входят).
- **Маркер исполнителя** `[pi:<роль>]` / `[hermes:<роль>]` (регистр не важен):
  - `[hermes:<роль5.3>]` → **DENY [MODEL_ENFORCE]** с подсказкой «используй pi
    роль-пак skills/pm-factory/pi/role-packs/<роль> (J59); делегация — только
    с обоснованием в журнале PLAN.md»;
  - `[pi:<роль>]` → пропуск (запись `model_enforce_pass` в лог);
  - маркера нет на боевом этапе → **WARN** в лог (`model_enforce_warn`),
    НЕ блок — миграционный период.
- **Флаг `FLOW_MODEL_ENFORCE`:** дефолт **ON** (в отличие от остальных флагов
  плагина — решение Заказчика: механика включена); `0/false/no/off` — полное
  отключение (деградация при недоступности Pi-инфраструктуры).
- plugin.yaml → 0.3.0. Тесты: tests/test_j60_model_enforce.py (22 кейса,
  TC-J60-001..014 — матрица ТЗ: pi→pass, hermes→DENY, без маркера→WARN,
  не-5.3→pass, флаг off→все pass, guard Ф2/4/5, регистр, эвристика).

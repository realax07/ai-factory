## Возврат ревью review-001 (2 major)

Цепочка зависимых задач на настоящих воротах получала DENY: dev_task
требует approve-ревью зависимостей (J10), а ревью шло одной стадией после
всех dev. Исправлено: `review: <роль-пак>` разворачивает пары dev-N →
review-N (code_review по задаче, вердикт `code-reviews/<pkg>/review-N-001.md`
— файл, который засчитывает J10); зависимые задачи без `review:` — STOP на
развертке. Зависимость на открытую не-dev/несуществующую задачу — STOP
сразу; per_task только для pi:dev без optional; коллизия id — STOP; нет
движка на resume — STOP, не AttributeError.

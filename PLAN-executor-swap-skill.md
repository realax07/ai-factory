## Цель

Возможность подставить Claude Code или Codex вместо одного участника
процесса или вместо оркестратора остается. Подставляем по процедуре, ворота
при этом не ослабляются. Адаптеры в `scripts/executors/` заранее не пишем:
скилл объясняет, как добавить адаптер, когда он понадобится.

## Состав

1. `skills/pm-factory/executor-swap/SKILL.md`: скилл ПМ. Уровни подмены:
   модель роли, исполнитель стадии, новый исполнитель (один модуль),
   оркестратор. Что сохраняется и что теряется при подмене, ошибки.
2. `docs/guides/external-orchestrator.md`: гайд «Claude Code / Codex как
   оркестратор»: что дает ПМ на Hermes, чего нет у внешнего оркестратора,
   как это компенсировать, порядок сессии, стоимость.
3. Ссылки: `agents/pm_agent.md` (таблица скиллов), `skills/README.md`
   (реестр), `docs/guides/pipeline-manifest.md` (правило `run:`),
   `docs/process-context.md` (исполнители).
4. Backlog: J65.10 «реальные исполнители» закрыт решением Заказчика; запись
   в J65 и строка в `backlog/MAP.md`.
5. Тест `tests/unit/test_executor_swap_skill.py`: скилл на месте, на него
   ссылаются промпт ПМ и реестр, в нем упомянут каждый исполнитель из
   `scripts/executors/`, пути из скилла существуют.

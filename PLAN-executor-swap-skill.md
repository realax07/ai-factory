## Цель

Возможность подставить Claude Code или Codex вместо одного участника
процесса или вместо оркестратора остается. Подставляем по процедуре, ворота
при этом не ослабляются. Адаптеры в `scripts/executors/` заранее не пишем:
скилл объясняет, как добавить адаптер, когда он понадобится.

   (реестр), `docs/guides/pipeline-manifest.md` (правило `run:`),

4. Backlog: J65.10 «реальные исполнители» закрыт решением Заказчика; запись

## Этапы и роли

Однопакетный Флоу 4 вне конвейера: пакет обслуживания фабрики делает
внешний агент (сессия Claude Code Заказчика) по п.21, как пакеты J64/J65.
Автор (этот worktree) → тесты + ci_local → независимое ревью отдельным
агентом с чистым контекстом и только статикой диффа, раунды до approve,

засчитывает Заказчик при merge: `pr_validate` ревью Флоу 4 не проверяет
(исключение описано в гайде внешнего оркестратора). Merge — по слову
Заказчика.

# BUG-AF-RECHECK-002: строка в goal выдает bypass за решение Заказчика

- Источник: внешний ревью-комплект (ChatGPT re-review), передан Заказчиком 2026-10-13
- Версия: 2e5f090; подтверждено чтением кода ПМ 2026-10-13
- Серьезность: major / приоритет P1
- Компонент: J43/J43.1 flow-enforcer, авторизация исключений

## Суть

`has_bypass()` (enforcer.py:334) — поиск подстроки «flow: bypass --by customer»
в goal; goal формирует сам оркестратор. Отдельного подтверждения решения
человека нет; упоминание маркера внутри цитаты/примера тоже активирует обход.
Ветка bypass в `flow_enforce()` возвращает None до parse_markers/run_prepare.
Тест test_d_bypass_marker_passes_and_logs закрепляет это поведение.

## Факт/ожидание

- Факт: goal с подстрокой → делегация разрешена при том же strict-состоянии.
- Ожидание: исключение — по отдельно проверенному решению Заказчика,
  привязанному к repo/scope/действию (и версии/периоду); текст goal может
  ссылаться на решение, но не удостоверяет его сам. Ошибка проверки решения
  не превращается в разрешение.

## Критерии исправления

- bypass-текст без подтвержденного решения → отклонение.
- Подтвержденное исключение действует только на указанный scope/действие;
  другой repo/scope, отозванное/истекшее — отклонение.
- Цитирование маркера в описании не активирует обход.
- Исключение и его основание — в аудите (bypass-лог с привязкой к решению).
- Возможность осознанного человеческого исключения сохраняется.

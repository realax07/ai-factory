## Статус

- 2026-10-13: open (в работе, PR #106, ветка pipeline/bug-af-recheck)

## Суть

`SCEN_RE` распознает только «Сценарий:», канонический OpenSpec-заголовок
«#### Scenario:» не читается (в specs/deterministic-flow/spec.md — 29 таких).
Ноль распознанных сценариев → «все сценарии покрыты», exit 0 даже с --strict.

## Факт/ожидание

- Факт: «Сценариев в спеках: 0 … Все сценарии покрыты кейсами», exit 0.
- Ожидание: Scenario распознается (29 шт.); 0 распознанных при входе-спеке —
  явное диагностическое состояние (не подтверждает покрытие); strict с
  пробелами — ненулевой exit.

## Критерии исправления

- Тест канонического «#### Scenario:» (рус+англ заголовок); русский формат сохранен.
- Негативные тесты: пустой/отсутствующий/неподдерживаемый вход.
- Непокрытый сценарий → ненулевой exit в strict; покрытый → успех.
- Согласовать источник ссылок TC с трассировкой Requirement/Scenario
  (отсутствие FR/SC не делает корректную ссылку сиротой автоматически).
- Зеркалирование фикса в ekotov-wiki (skills/).
